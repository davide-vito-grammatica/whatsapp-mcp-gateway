Scegli come associare il proxy

Usato solo in memoria per questa pagina. Non utilizzare il token MCP.

Apri WhatsApp → Dispositivi collegati → Collega un dispositivo e scansiona il QR code.

  1. Apri WhatsApp sul telefono.
  2. Vai in Impostazioni o menu → Dispositivi collegati.
  3. Seleziona Collega un dispositivo.
  4. Scegli Collega tramite numero di telefono.
  5. Inserisci il codice visualizzato.
  6. Attendi la conferma della connessione.
